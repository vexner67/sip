# Скорость: Sip против C, Go и Python

`./run.sh` (Apple M-серия, clang 21 -O3, Go 1.27, Python 3.12). Секунды, лучшее из 3 запусков.

| тест | Sip | C | Go | Python | Sip быстрее Python |
|---|---|---|---|---|---|
| fib(35), рекурсия | 0.034 | 0.028 | 0.036 | 0.629 | ×18 |
| решето до 20 млн, циклы и массивы | 0.057 | 0.038 | 0.061 | 3.475 | ×61 |
| 2 млн строк, словарь частот | 0.103 | — | 0.140 | 0.538 | ×5 |
| 3 млн float, сортировка | 0.212 | — | 0.256 | 1.133 | ×5 |

Вывод Sip совпадает с Python байт в байт. На тестах со строками и словарями
выигрыш меньше: там и в Python работает код на C (dict, str), а время уходит на
выделение памяти.

Sip проверяет переполнение `int`, а C в этой таблице нет. Больше всего это стоит в fib:
проверка `fib(n-1) + fib(n-2)` не даёт clang переписать рекурсию через накопитель.
