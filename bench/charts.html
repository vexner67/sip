Компилятор на Sip против компилятора на Python

Проверка типов и генерация C (без clang), миллисекунды, лучшее из 7 запусков. Меньше — лучше. Оба выдают одинаковый C байт в байт.

Как мерили

  • Программы: bench/speed, запуск ./run.sh. Apple M-серия, clang 21 -O3, Go 1.27, Python 3.12. Вывод Sip совпадает с Python байт в байт.
  • Sip проверяет переполнение int и границы списков, C в этой таблице нет. Сильнее всего это видно в fib.
  • Токены: bench/count_tokens.py, задачи и варианты синтаксиса в bench/samples. Sip здесь — выбранный вариант E (гибрид). Код на C не считали.
  • Компилятор: selfhost/sipc.sip (собран сам собой) против siplang на Python; время Python включает запуск интерпретатора, потому что его платит каждый вызов. Сверка C на 300 программах: python3 selfhost/parity.py --only cgen.
