# Sip на Sip

Компилятор Sip постепенно переписывается на самом Sip. Каждая часть должна
выдавать ровно то же, что эталон на Python в `siplang/`: это проверяет
`python3 selfhost/parity.py` (и тест `SelfhostTest`).

| Часть | Python | Sip | Статус |
|---|---|---|---|
| Лексер | `siplang/lexer.py` | `lexer.sip` | готов: токены, позиции и ошибки совпадают |
| Парсер | `siplang/parser.py` | `parser.sip` | готов: дерево и ошибки совпадают |
| Проверка типов | `siplang/checker.py`, `siplang/types.py` | `checker.sip` | готова для программы из одного файла: типы всех выражений и ошибки совпадают |
| Генерация C | `siplang/cgen.py` | — | ещё на Python |

```bash
sip run selfhost/lexer.sip FILE.sip    # токены построчно
sip run selfhost/parser.sip FILE.sip   # дерево, узел на строку
sip run selfhost/checker.sip FILE.sip  # дерево с типом каждого выражения или первая ошибка
python3 selfhost/parity.py             # сравнение с Python на всех .sip репозитория
python3 selfhost/parity.py --corpus    # собрать программы из набора тестов (~/.cache/sip/selfhost-corpus)
python3 selfhost/parity.py --only checker
```

Проверку типов сравнивает тот же `parity.py`: обе стороны печатают дерево
после проверки, и у каждого выражения стоит его тип (`Name@3 :: [int]`), либо
выводят первую ошибку. Входы: файлы репозитория, трудные случаи из `parity.py`
и программы, которые компилирует набор тестов (среди них много программ с
ошибками типов). Сравниваются только программы из одного файла: импорт других
файлов `.sip` — это загрузчик модулей (`siplang/modules.py`), его ещё нет на
Sip. Встроенные модули (`math`, `json`, `http`, ...) поддерживаются: в
`checker.sip` есть своя часть переименования (`math.sqrt` становится одним именем),
которую делает загрузчик.

Дерево в `parser.sip` — один общий узел `N(kind, line, s, kids, ty)`: `kind` — имя
класса из `siplang/nodes.py`, дети идут в порядке его полей. Листья: строка
(`str`), `None`, `bool`, список (`list`) и кортеж (`tuple`). Поля extern-функций
лежат в дополнительном ребёнке `extern`.

`ty` — номер типа узла в таблице проверки типов. Типы в `checker.sip` — тоже один
вид `Ty` с полем `k` (prim, list, tvar, record, ...); тождество объектов Python
заменено номером `id`.

Лексер и парсер разбирают сами себя и весь код репозитория, включая стандартную библиотеку.
